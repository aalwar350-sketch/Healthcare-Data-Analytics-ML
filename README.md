# Healthcare-Data-Analytics-ML
A comprehensive data science project focused on predicting healthcare visit costs using Regression (Linear, Ridge, Lasso) and grouping patients through K-Means Clustering. Includes data cleaning, EDA, and handling missing values.

# Healthcare Data Analytics & Machine Learning Project

## 📌 Project Overview
This project is part of the **Fundamentals of Data Science** course at Badr University in Assiut. The goal is to analyze a synthetic healthcare dataset, handle missing data, and apply both Supervised and Unsupervised learning techniques to extract meaningful insights.

## 🚀 Key Features
- **Data Preprocessing:** Handled missing values using Mean and Mode imputation.
- **Supervised Learning:** Predicted patient visit costs using **Linear, Ridge, and Lasso Regression**.
- **Unsupervised Learning:** Segmented patients into clusters using **K-Means Clustering** and the **Elbow Method**.
- **Exploratory Data Analysis (EDA):** Visualized distributions and correlations using Seaborn and Matplotlib.

## 📊 Results
The regression models achieved a consistent performance:
- **Best Model:** Ridge Regression
- **Metric:** RMSE ~ 519.93

## 🛠️ Technologies Used
- Python
- Pandas & NumPy
- Scikit-Learn
- Matplotlib & Seaborn
